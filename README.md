# Winning With X39

Static multi-page website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create an empty GitHub repository.
2. Push this folder to the repository's `main` branch.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

GitHub will publish the site at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
All internal links and video paths are relative so the site also works when hosted
under a repository subpath.

The site contains about 353 MB of video. The initial push and Pages deployment may
take several minutes, but every individual file is below GitHub's 100 MB file limit.
